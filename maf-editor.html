Для резервной копии скачайте JSON.

Загрузка редактора…

Для экспорта PNG из локального каталога запустите «Запустить_Портал.bat» и откройте редактор через локальный сервер. Интернет для этого не нужен. Либо загрузите собственные изображения кнопками ниже.

Добавить МАФ

Нажмите карточку, чтобы добавить. Для замены выбранного слоя включите переключатель.

Закрасьте оборудование и его тень. Розовый участок будет передан ИИ для замены.

Перетаскивайте МАФ мышью или пальцем. Квадратный маркер меняет размер. Стрелки — сдвиг, Shift + стрелка — крупный шаг. Масштаб изображения не определяет реальный размер оборудования.

Слои монтажа

Добавьте МАФ из каталога или выберите существующий слой.

Параметры МАФа

Удаляется светлый фон, связанный с краями изображения. Если детали исчезли, отключите эту опцию.

МАФы, уже нарисованные в исходном рендере, выделяются маской. Удаление слоя убирает только добавленный объект.

ФОТОРЕАЛИСТИЧНАЯ ЗАМЕНА

От монтажа к новому рендеру

1. Отметьте старый МАФ инструментом «Участок для ИИ».
2. Добавьте новый МАФ и задайте его положение.
3. Опишите замену и скачайте пакет для обработки.

Этот сайт собирает задание. Генерация выполняется через ИИ в чате: прикрепите ZIP и попросите обработать рендер. Автоматическая генерация на сайте пока не подключена.

В ZIP: исходник, монтаж, маска, карточки выбранных МАФов, задание и редактируемый проект. ИИ-результат можно загрузить как фон нового монтажа. Проверка размеров, креплений и зон безопасности выполняется при проектировании.

Проект сохраняется в этом браузере, если доступно локальное хранилище. Для переноса и резервной копии скачайте JSON. Новые варианты не меняют исходные сметы и статусы согласования.
